# OWSENSE
### 영웅은 알지만, 무엇을 해야 할지 막막한 플레이어를 위한 오버워치 운영 학습 서비스

멘토링에서 반복해서 발견한 운영 실수를 정리한 가이드에서 출발해, **읽고 → 상황을 판단하고 → 자신의 조합에 적용하는 웹사이트**로 확장한 프로젝트입니다.

> 판단 연습에서 상황 문제를 풀어본 뒤, 운영과 복기에서 양 팀 조합과 자신의 영웅을 선택하면 역할에 맞는 행동 안내를 확인할 수 있습니다.

## 왜 만들었나요?

오버워치 멘토·멘티 활동 중, 영웅의 스킬을 알고 있어도 **언제 싸워야 하는지, 어디에 서야 하는지, 누구를 도와야 하는지**에서 반복적으로 혼란을 겪는 모습을 발견했습니다.

개별 플레이를 설명하는 데서 그치지 않고, 자주 틀리는 판단을 다시 찾아보고 연습할 수 있도록 초보자 가이드를 만들었습니다. 이후 내용을 읽는 것만으로 실제 행동을 정하기 어렵다는 문제를 해결하기 위해 판단 연습과 조합별 행동 안내를 웹사이트로 확장했습니다.

## 어떤 경험을 제공하나요?

| 기능 | 사용자가 할 수 있는 일 |
| --- | --- |
| **초보자 가이드** | 인원수·엄폐·거리·스킬·구도·역할·궁극기 등 7개 장을 삽화와 함께 학습합니다. |
| **판단 연습** | 기본 22개·응용 10개, 총 32개 상황에서 행동을 선택하고 판단 근거를 확인합니다. |
| **역할별 체크** | 탱커·메인딜러·서브딜러·메인힐러·서브힐러의 역할과 행동 기준을 확인합니다. |
| **운영과 복기** | 맵·공수·양 팀 영웅과 자신의 역할을 입력해 조합의 주의점과 행동 안내를 확인합니다. |
| **학습 기록** | 같은 브라우저에서 확인한 문제와 체크 상태를 저장하고 이어서 학습합니다. |

## 어떻게 발전시켰나요?

**멘토링에서 문제 발견 → 가이드 작성 → 웹사이트로 확장 → 사용자 피드백으로 개선**

| 발견한 문제·피드백 | 반영한 내용 |
| --- | --- |
| 조합 설명을 읽어도 자신이 무엇을 해야 하는지 알기 어려움 | 선택한 영웅의 역할에 따라 행동 카드를 다르게 제공합니다. |
| 가이드를 읽지 않으면 판단 문제의 자체 용어를 이해하기 어려움 | ‘황족’ 같은 자체 비유를 판단 연습에서 제거하고 역할명과 상황 중심으로 다듬었습니다. |
| 글만으로 위치와 지형을 이해하기 어려움 | 현재 배치 개념도, 벽·엄폐 아이콘, 고지대 측면도를 추가했습니다. |
| 일부 인원만 그린 그림이 수적 차이로 읽힐 수 있음 | 불필요한 나머지 인원을 제거하고, 상황에 직접 등장하는 대상과 인원수 문제의 조건을 구분합니다. |
| 고지대를 무조건 사용하거나 탱커만 공격하라는 안내로 오해할 수 있음 | 상황별 예외와 행동 조건을 문구에 반영했습니다. |

사용자 피드백을 바탕으로 콘텐츠와 사용 흐름을 계속 개선하고 있습니다.

## 프로젝트에서 맡은 일

- **문제 정의:** 멘토링에서 반복되는 운영 실수와 학습자의 혼란을 정리
- **콘텐츠 설계:** 운영 가이드, 역할 분류, 상황 문제와 판단·해설 기준 작성 및 검토
- **서비스 기획:** 가이드·판단 연습·역할 체크·조합별 행동 안내의 흐름 설계
- **개선 및 검증:** 사용자 피드백을 문구·기능·시각화 개선으로 연결하고 결과 확인

웹 구현과 수정에는 AI 코딩 도구를 활용했으며, 운영 기준과 콘텐츠의 판단·검토를 직접 진행했습니다.

## 로컬에서 실행하기

저장소 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000`을 엽니다.

```sh
python -m http.server 8000
```

문제 데이터와 화면 코드 검사는 다음과 같이 실행합니다.

```sh
python scripts/validate_questions.py
node --check app.js
node scripts/test_ui.cjs
```

GitHub Actions로 문제 형식과 화면 회귀 검사를 실행합니다. 운영 사이트 배포는 GitHub 변경과 별도로 관리합니다.
