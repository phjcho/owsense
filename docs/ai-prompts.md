# 친구의 AI에 전달할 요청

AI에 저장소 접근 권한이 있으면 아래를 그대로 전달한다. 접근할 수 없다면 AGENTS.md, docs/guide.md, docs/question-authoring.md, templates/question.json, questions.json을 내려받아 함께 첨부한다. 저장소 주소만 보냈다고 비공개 파일을 읽을 수 있는 것은 아니다.

## 새 문제 초안 만들기
```
이 저장소의 AGENTS.md를 먼저 읽어줘. docs/guide.md의 관련 원문과
출제 기준, 기존 questions.json을 확인하고 [주제] 판단 문제 [개수]개를 만들어줘.
조건 하나로 판단이 달라지는 문제 쌍도 포함해줘.
먼저 각 문제의 근거 소제목, 핵심 단서, 세 선택지의 판단 이유,
반례, 확인이 필요한 사실을 보여줘. 그다음 기존 형식의 JSON을 제시해줘.
근거가 없는 수치와 조건은 만들지 말고, 애매한 부분은 질문해줘.
아직 questions.json에 넣거나 기존 문제를 수정하지 말아줘.
```

## 독립 검토하기
```
가이드와 출제 기준을 먼저 읽고 이 초안을 검토해줘.
정답을 모른다고 생각하고 세 선택지를 각각 지지할 수 있는지 살펴봐줘.
둘 이상 타당하면 억지로 정답을 고르지 말고 부족한 조건을 지적해줘.
해설에만 있는 정보, 과도한 일반화, 기존 문제 중복, 정답 위치 편향을 확인해줘.
패치 의존 사실은 검증 여부를 따로 적어줘. 파일은 수정하지 말아줘.
```

## 승인 후 편입하기
```
승인한 문제만 questions.json 배열에 추가해줘.
기존 문제와 id를 보존하고 중복 id가 없는지 확인해줘.
python scripts/validate_questions.py 를 실행하고 결과를 알려줘.
새 브랜치에서 PR로 제안하고, 본문에 근거와 사람 검토 상태를 적어줘.
현재 사이트에 자동 반영됐다고 안내하지 말아줘.
```
