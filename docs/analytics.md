# 이용 통계

운영 사이트의 `/stats`에서 소유자 ChatGPT 계정으로 로그인해 확인합니다. 소유자의 이메일은 서버 환경 변수 `ANALYTICS_ADMIN_EMAIL`로 지정하며 저장소에 넣지 않습니다. 다른 로그인 계정과 비로그인 사용자의 통계 API 접근은 차단합니다.

| 이벤트 | 집계 기준 |
| --- | --- |
| visit | 브라우저 탭의 세션당 1회 |
| page_view | 주요 화면이 표시될 때마다 |
| practice_start | 세션에서 첫 문제를 열거나 채점할 때 1회 |
| question_start | 문제를 열 때, 세션·문제별 1회 |
| question_complete | 판단 확인하기를 누를 때, 세션·문제별 1회 |
| practice_complete | 같은 세션에서 전체 32문제 채점을 완료했을 때 1회 |
| analysis_use | 입력 검사를 통과해 운영 안내 결과를 표시할 때마다 |

방문자는 브라우저에 저장한 무작위 UUID로 추정하며 실인원이 아닙니다. 세션은 해당 탭에서 30분 동안 활동하지 않으면 갱신합니다. 차단·전송 실패·저장소 삭제·자동화 트래픽으로 실제 이용과 차이가 있을 수 있습니다. 정답·오답·선택 조합·이름·이메일·IP·전체 URL은 통계 테이블에 저장하지 않습니다. 날짜 기준은 한국 시간이고 이벤트는 90일간 보관합니다. 연결 이전 이용은 복원되지 않습니다.

개별 문제 완료율은 시작한 문제 중 채점을 마친 비율이며 실력이나 학습 효과를 뜻하지 않습니다. 처음부터 끝까지 푼 세션 수와 분리해서 표시합니다.

## 수집 제어와 테스트

`/privacy`에서 해당 브라우저 수집을 중단할 수 있습니다. Do Not Track이 설정된 브라우저는 수집하지 않습니다. `/?analytics_test=1`로 진입해 수행한 이벤트는 테스트 표식을 가지며 관리자 통계에서 제외됩니다. 테스트 이후 일반 이용을 확인하려면 새 탭에서 일반 사이트 URL을 엽니다.

## 서버 구성

기존 HTML·CSS·JS는 그대로 제공하고 Cloudflare Worker가 이벤트 수집과 통계 API를 처리합니다. Cloudflare D1의 `analytics_events` 테이블에 저장합니다. 공개 수집 API는 동의된 이벤트 종류·문제 ID·원본 도메인·본문 크기를 검사합니다. 세션별 시작·완료는 서버에서도 중복을 제거합니다. 브라우저가 보낸 이용 이벤트이므로 조작 방지된 실적 인증 자료는 아닙니다.

`worker/`는 API와 통계 화면, `db/`와 `drizzle/`은 스키마와 생성된 마이그레이션, `scripts/build-analytics.mjs`는 기존 사이트와 Worker를 함께 묶는 빌드입니다. 실제 Sites 식별자와 관리자 이메일은 저장소에서 제외합니다. `hosting.example.json`은 바인딩 예시입니다.

```sh
npm ci
npm run build
npm test
```

Node.js 24 이상에서 테스트합니다. 로컬 정적 서버로 기존 화면은 체험할 수 있지만, 수집 API·관리자 로그인·실시간 집계에는 Worker와 D1이 필요합니다. GitHub Pages 자체에서는 서버 통계가 작동하지 않습니다.
