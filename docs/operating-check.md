# 운영 판단 점검

공통 10문항, 문항별 5개 보기 중 하나를 선택하고 일괄 제출합니다. 탱커·서브딜러·메인딜러·서브힐러·메인힐러는 준비 중으로 표시합니다.

## 출제·복습 기준

- 조합에 맞는 거리와 자리, 실제 교전 참여, 궁극기 대응과 배분을 점검합니다.
- 고지대 가장자리와 안쪽의 시야, 처치된 상대의 역할, 상대 궁 보유 여부와 엄폐 가능 여부를 명시했습니다.
- 성립하는 대안은 함께 인정합니다. 각 보기의 해설로 조건과 비용을 설명합니다.
- 결과는 이번 문항에서 놓친 조건만 다룹니다. 성향·티어나 검증된 실력 지표로 해석하지 않습니다.
- 모든 문항은 초보자 가이드의 관련 소제목으로 직접 연결합니다. 단순 가이드 첫 화면 링크가 아닙니다.

## 구현

`exam-data.js`에 문항, 보기, 인정 답안(0부터 시작), 보기별 해설, 복습 기준과 가이드 연결을 저장합니다. `exam.js`는 응시·결과 화면과 답안 저장을 담당합니다. 기존 판단 연습 문제와 기록은 독립적으로 유지합니다.

브라우저에 최근 답안을 저장하며, 제출되지 않은 문항이 있으면 해당 문항으로 이동합니다. 저장 데이터의 버전과 선택 범위를 검증합니다. 개별 답안은 서버 통계로 전송하지 않습니다.

## 확인

`npm test`로 기존 통계 검증과 신규 문항 형식·인정 답안·영역별 집계·가이드 연결·저장 데이터 검증을 실행합니다. `npm run build`로 배포 파일을 생성합니다.
